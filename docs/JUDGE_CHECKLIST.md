# Five-minute judge walkthrough

Updated September 27, 2026. This is a checklist to execute, not a claim of completion.

- [ ] **Profile:** Open the local frontend. Try Continue without skills; try “Astronaut”; add “T-SQL” and confirm SQL; reject a duplicate; add Excel and Communication.
- [ ] **Role:** Confirm Junior Data Analyst, stored requirement weights, and disclosure of real/sample data. Delayed data must show loading rather than a blank screen.
- [ ] **Evidence:** Select SQL Course, Excel Self-Declared, Communication Self-Declared. Confirm that evidence is self-reported.
- [ ] **Analysis:** Click Run Analysis. Confirm visible Results without a hang or crash; diagnostics should show one profile POST followed by one analysis POST.
- [ ] **Results:** Confirm a sensible one-decimal percentage and the requirement-match disclaimer. Gaps must have defined weighted values and explanations; no NaN, blank role, or invented status.
- [ ] **Roadmap:** Review up to three available gaps in prerequisite order. Fully covered requirements must not create artificial gaps.
- [ ] **Tutor:** Open one gap. Confirm readable content and a source badge matching the returned source. Try Simple, Visual, Example-based, Step-by-step and Arabic. Different styles should teach the same selected skill.
- [ ] **Rapid switching:** Switch styles quickly; an old response must not overwrite the final selected style.
- [ ] **Failure behavior:** In a controlled no-key setup, confirm Curated Example. An actual provider failure may wait up to the timeout; do not label fallback as live.
- [ ] **Reset:** Start over; confirm no previous skills/result/tutor content in the new wizard session. Database history is not deleted by UI reset.
- [ ] **Repeat:** Use a different profile and confirm a different explainable result.
- [ ] **Record:** Tester name, date, elapsed walkthrough time and issues. Complete without coaching before calling this independent human verification.

Agent-operated results and test fixtures are recorded separately in `VERIFICATION_2026-09-27.md`.
